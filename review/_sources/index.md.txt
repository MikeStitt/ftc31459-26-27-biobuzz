# What the student writes

Every blank on the lessons line at `HEAD`, filled one at a time from the
solutions line at `solutions-03`, and grouped by the lesson that asks for it. Each
page is one lesson, each section one file, and each diff is one edit a student
makes.

A blank in a file not named for a lesson belongs to the lesson its marker names, so
LessonsDriveTrain's five blanks land on three different pages.

The edits are grouped by where the two files differ, not by the TODO numbering, so
a run holding three markers is one edit and is named after all three. Where the
alignment puts a blank line in a different place, a line can also arrive one edit
earlier than the TODO that asks for it.
