## Why those terms and not looser ones

The guide leans on Game Manual 0, which is licensed **CC BY-NC 2.0 Generic**
(<https://gm0.org/en/latest/docs/appendix/license.html>, read 2026-09-27). No page copies GM0's
words: `task.l5` explains the mecanum rollers in its own and names GM0's page as where that
explanation comes from. CC BY-NC 4.0 keeps every restriction GM0's license asks anyway, attribution
and non-commercial use both, so whether any page counts as an adaptation does not have to be
settled.

What has not been established: whether looser terms would be permitted. Section 4 of the CC BY-NC
2.0 legal code was read on 2026-09-27 and carries no sentence naming the license a derivative work
must use. That is not the same as establishing that any license would do, and nothing here relies on
it.
